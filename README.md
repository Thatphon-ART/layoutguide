# Layout Guide

ใส่ภาพต้นแบบ กด **✨ Click** ได้ไกด์จัดวาง 7 ไซส์รวมในภาพเดียว ด้วย Nano Banana (Gemini) ผ่าน Puter.js

ไซส์: 16:9 · 1:1 · 9:16 · 4:3 · 2:1 · 8:1 · 3:16

- ส่ง AI ครั้งเดียวต่อ 7 ไซส์ แล้วเว็บตัดและจัดลงแผ่นสรุปให้อัตโนมัติ
- มุมขวาบนแสดงบัญชีที่ใช้ + เครดิต Puter ที่เหลือต่อเดือน (กด "เปลี่ยน" เพื่อสลับบัญชี)
- เว็บทั้งหมดอยู่ในไฟล์เดียว `index.html` ไม่มีเซิร์ฟเวอร์
